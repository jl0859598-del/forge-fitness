# 炼 FORGE · 训练与营养

移动端优先的健身训练与营养 Web 应用，纯静态部署。

功能：

- 301 个动作库，含目标肌群、要点、常见错误与标准行程轨迹
- 按身体数据、目标、经验、器械条件生成个性化训练计划与次数/组数
- 体重与训练记录（保存在本机浏览器 localStorage）
- 营养与餐单建议、研究文献索引、教练与动作视频检索
- 拍照估算热量（需后端 `/api/analyze`，静态版不可用）
- 本地视频姿态分析（MediaPipe Pose Landmarker，视频不上传）

## 本地运行

```bash
python3 server.py
```

拍照估算热量需要在同目录 `.env` 中配置 `OPENAI_API_KEY`（见 `.env.example`）。

## 部署

本仓库即发布目录，GitHub Pages 直接托管根目录。所有路径均为相对路径，可部署在任意子路径下。
